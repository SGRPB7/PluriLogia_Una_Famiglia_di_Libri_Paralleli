# PluriLogia_Una_Famiglia_di_Libri_Paralleli
Raccolta di articoli di analisi critiche comparative e dialoghi con Gemini Notebook in qualità di Critico Letterario Professionista, sulla Saga : **PluriLogia ― Una Famiglia di Libri Paralleli**. Essa è di genere Ibrido / Sperimentale (*SciFi, Fantasy, SteamPunk, Gatti, Vampiri, Erotica, Weird / eccentrico / mistero, Religioso, Epico*).
Sono inclusi vari tipi di opere derivate (*SpinOffs*) : 
1. Riassunti sinottici brevi
2. Sinossi estese
3. Schede tecniche di descrizione schematica (Quarte di Copertina)
4. Indici Strutturali (Liste di Titoli dei Capitoli)

nella sezione "verticale" ed ogni sorta di articoli tematici sugli archetipi e leitmotiv strutturali nella sezione "orizzontale".
Sono inclusi anche due pacchetti coi sorgenti GAMBAS di un nostro software per l'analisi dei clusters lessicali semantici.
